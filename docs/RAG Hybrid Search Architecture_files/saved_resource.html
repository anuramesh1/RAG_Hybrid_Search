RAG Hybrid Search Architecture

Two flows share one ChromaDB index. Ingestion turns the Markdown files in docs/ into embedded chunks. The query flow runs a LangGraph pipeline that finds chunks with keyword and vector search, merges the rankings, and asks gpt-4o-mini for a cited answer.

What happens when you ask a question

  1. You type a question in the Streamlit page. The app calls graph.invoke() with the query and an empty state.
  2. retrieve_node scores every chunk with BM25 and asks ChromaDB for the 10 nearest vectors. RRF merges the two rankings and keeps the top 5.
  3. If retrieval fails (for example, no index yet), the graph sets state.error and jumps to END. The page shows the error.
  4. build_prompt_node writes a system prompt that says to answer only from the chunks, refuse if the answer isn't there, and cite [Source: doc, Section: …].
  5. generate_node sends the prompt to gpt-4o-mini and pulls the citations out of the reply with a regex.
  6. Streamlit shows the answer, the citations, the 5 retrieved chunks with their RRF scores, and the BM25/vector/RRF trace it captured from stdout.
